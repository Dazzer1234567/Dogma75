4Bookmarks

TriggerAction
Pad 13 tapAdd a bookmark at the current playhead + open text-input to name it. Rejected if within 2 s of an existing bookmark — the OLED briefly shows MARKER SKIPPED (too close).
Pad 13 held + Pad 0Next bookmark — jump the playhead to the first bookmark strictly after the current position.
Pad 13 held + Pad 4Previous bookmark — jump to the last bookmark strictly before the current position.

Every nav press MOVES — never "selects where you already are". No wrap; clamps at both ends with a brief (at first) / (at last) OLED banner. The triangle tip is pixel-aligned to the playhead, so navigating lands exactly on the marker.

6Channel entry mode

Sets a track's input or output channel routing. Supports non-adjacent stereo (e.g. input 1 & 7). Pads 20 & 21 LEDs flash while active; the DAW's input/output field pulses red in sync.

TriggerAction
Pad 12 held + Pad 0Enter INPUT channel-entry mode.
Pad 12 held + Pad 4Enter OUTPUT channel-entry mode.
Number padsType a decimal number, up to 2 digits: Pad 1=1, 2=2, 3=3, 5=4, 6=5, 7=6, 9=7, 10=8, 11=9, 15=0.
Pad 20Commit current number as the LEFT channel and switch to typing the RIGHT channel.
Pad 21Commit & exit. One number → mono; two numbers → stereo.

Example: hold 12, tap 0, then 1, 0, Pad 20, 1, 1, Pad 21 → input from channels 10 & 11.

7Antelope interface

TriggerAction
Pad 35 tapToggle Input Monitor on the selected track. Sends a mute change to the Antelope mixer for that track's output channel(s).
Antelope mixer mute (any source)DAW follows: reader thread listens for set_mixer_cfg broadcasts and reflects them back into the corresponding tracks' monitor state.

Sharing rules for shared output channels: if ANY track routed to a channel has monitor ON, that channel is unmuted on the Antelope. Only when EVERY track routed to it has monitor OFF is the channel muted.

8View & navigation

TriggerAction
E1Silent playhead scrub. If playing, playback pauses and auto-resumes 100 ms after the last encoder tick.
E2Zoom timeline (logarithmic, 1 M× max). No-op while zoom lock is active.
Pad 24 held + E2Pan the timeline horizontally. Works even while zoom is locked.
Pad 26 held + E3Scroll timeline view.
Pad 24 held + E6Audio scrub — plays back at variable speed based on encoder rate. Fast-mode multiplier kicks in above threshold. Clamped to ±8×.
Pad 23 held + E6Toggle zoom lock. Fires once per pad-23 hold. When locked: E2 zoom is disabled; pan still works. Amber padlock icon in the OLED top-right and in the bottom-right of the arrangement view. Same gesture unlocks.

After a pad 23 + E6 zoom-lock toggle, E6 marker-nudge (for loop-R) is suppressed for 500 ms so residual finger motion coming off the encoder can't accidentally nudge the marker.

9Undo

Two independent histories. Content undo doesn't touch the view; view undo doesn't touch recordings.

TriggerAction
Pad 36 tap-releaseCONTENT undo: rewinds record / delete / mixer / track add / rename. Leaves playhead, markers, zoom, view center alone.
Pad 36 held + Pad 20 / 21 / 22 / 23VIEW undo: rewinds the last playhead / marker-position / zoom / view-pan gesture. Leaves tracks and mixer alone.
Pad 26 tap (no combo)Also fires content undo — alternative to pad 36.

Continuous gestures (scrub, zoom, pan, marker nudge) create ONE view-undo entry per gesture — snapshotted at the START of the burst and coalesced against a 500 ms activity window. So a 5-second scrub is walked back in a single pop.

11Modes

ModeEnter / Exit
Clear-markers (loop-edit)Enter: Pad 15 short tap. Exit: Pad 15 tap again, or any marker encoder move.
Pad 24 tap = arm delete (LED 8 solid); pad 20/23 = delete loop pair; pad 21/22 = delete record pair.
Zoom lockToggle: Pad 23 held + E6 turn (once per hold). When locked, E2 zoom is a no-op; padlock icon shows in OLED top-right and arrangement bottom-right. Persists in-memory only — always OFF on fresh DAW launch.
Channel entry exclusiveEnter: Pad 12 held + pad 0/4. Exit: Pad 21 (commit) or Pad 20 (advance to right channel — see §6). Firmware enters DAW-exclusive mode: all local pad behaviours (LOOPPLAY, DELETEPAIR, predictive LEDs) are suppressed for the duration.
Text-input (rename)Enter: Pad 12 long-press or Pad 13 tap. Exit: Pad 21 (commit) or timeout on DAW disconnect. See §5.
Diagnostic displayDefault at boot. OLED shows raw pad and encoder events. All pad/encoder input is inert on the DAW side.
Descriptive displayOLED shows DAW-pushed text.
Toggle: Pad 3 held + Pad 23. Refused if DAW isn't sending heartbeats.
Hard resetTrigger: Pad 18 held ≥ 3 s. All 9 LEDs light + OLED shows RESET; on release, firmware sends RESYNC to force the DAW to re-push all state.
